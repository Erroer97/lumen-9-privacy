2. Allgemeine Informationen

Der Schutz personenbezogener Daten ist uns wichtig. Diese Datenschutzerklärung erläutert, welche Daten bei der Nutzung von Lumen-9 verarbeitet werden können und zu welchen Zwecken dies geschieht.

Bei der Nutzung von Lumen-9 können abhängig von der technischen Umsetzung folgende Daten verarbeitet werden:

lokal gespeicherte Spielstände und Spieleinstellungen;

Spielstände, die ausschließlich lokal auf dem Gerät gespeichert werden, werden nicht allein dadurch an NeonFoundry übermittelt. Diese Aussage gilt nicht, falls später eine Cloud-Speicherung oder eine andere Online-Funktion hinzukommt.

4. Werbung durch Google AdMob

Für die Einblendung von Werbung ist die Nutzung von Google AdMob, einem Werbedienst von Google, vorgesehen.

Wenn Google AdMob integriert ist, können durch das Google Mobile Ads SDK insbesondere folgende Daten verarbeitet werden:

IP-Adresse und daraus gegebenenfalls abgeleitete ungefähre Standortinformationen;

Interaktionen mit der App und mit Werbeanzeigen, beispielsweise Anzeigenaufrufe und Klicks;

technische Diagnose- und Leistungsdaten;

Werbe-ID von Android und weitere Geräte- oder Kennungen, soweit diese verfügbar sind und verwendet werden.

Diese Daten können zur Auslieferung und Personalisierung von Werbung, zur Messung der Anzeigenleistung, zur Analyse und zur Erkennung beziehungsweise Verhinderung von Betrug verarbeitet werden. Welche Daten im Einzelfall verarbeitet werden, hängt unter anderem von der verwendeten SDK-Version, den Einstellungen und den Einwilligungsentscheidungen ab.

Empfänger können Google und die an der Werbeauslieferung beteiligten Werbepartner sein. Dabei kann eine Verarbeitung auch außerhalb des Europäischen Wirtschaftsraums stattfinden. Soweit erforderlich, müssen hierfür geeignete datenschutzrechtliche Garantien bestehen.
